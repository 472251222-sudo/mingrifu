# 明日复独立成长游戏产品规格

版本：MVP 1.0，2026-10-14。依据用户最新确认的12项产品核心；产品方向讨论已结束。下列小型数值与交互细节由Manager在授权范围内确定，后续可调，不要求重新确认产品方向。本文是长期产品规格，阶段状态仍在growth-game.md。

## 1. 用户与价值

面向希望把现实中的学习、工作、运动等努力变成可见积累，又希望轻松布置个人空间的用户。世界代表用户本人，长期存在，不绑定某一个目标。价值是努力有回响、积累不归零、创造可自由调整；不是效率排名、签到压力或资源维护游戏。

## 2. MVP边界与循环

首次进入自己的林缘世界 → 记录一项模拟努力 → 获得永久XP和可花费BP → 自然环境发生变化/达到新阶段 → 选择建筑或装饰自由布置 → 积累BP扩张相邻土地 → 保存后再次进入继续建设。

双轨并行：自然成长由努力积累驱动，人工布局由用户决定。建造不反向产生XP/BP，避免刷资源闭环。第一版明确标“模拟努力”，不读取/修改明日复正式任务、目标、计划或排程；不声称已验证真实努力。

技术保留React+Canvas，32px正交方形Tilemap、3/4透明Sprite、最近邻缩放。独立入口、启动、构建和预览不加载V3业务入口；P1/P1.1和P2-B预览继续保留。

非目标：复杂多货币、商店交易、维护成本、天气、昼夜、断签、衰退、排行榜、多人、账号、云同步、真实任务奖励接入、新引擎、复杂地形高度、室内或新批量美术。

## 3. 成长事件与资源

事件字段：唯一字符串id、source=`simulation`、minutes（整数1..180）、occurredAt（有效ISO时间）；可选短label仅用于历史展示。事件可由10/25/50分钟快捷项或自定义分钟产生。UI提交一个事件时只创建一次id；保存失败重试保持同id。系统按id幂等，重复事件不再次改变XP/BP/生态/世界revision；相同id但不同内容拒绝。坏事件在任何状态改变前拒绝。

集中数值文件为`src/growth/game/balance.js`：初始BP30，XP0；事件XP=minutes，BP=floor(minutes/5)。示例10分钟→10XP+2BP；25→25XP+5BP；50→50XP+10BP；3分钟→3XP+0BP。XP不消费、不衰退、不因花BP或移动/收纳降低。BP不能为负；不足则拒绝整项消费，不能先扣后报错。资源与状态使用安全整数，非法/溢出输入拒绝，不静默归零。

所有价格、阶段阈值、生态间隔、地图区块、事件范围及初始赠送配置集中管理；UI和规则使用同一配置，不在不同组件散落价格。第一版参数是可调的平衡基线，不是现实努力价值量化标准。事件历史与去重数据跟随世界存档；不以删除旧事件记录破坏幂等。

## 4. 阶段与解锁

| 阶段 | XP阈值 | 解锁 |
| --- | ---: | --- |
| 萌芽 | 0 | 木屋、草丛、野花、灌木、石头；初始土地内自由建造 |
| 扎根 | 120 | 阔冠树、两种栅栏、信箱；相邻土地扩张 |
| 丰茂 | 300 | 高冠青杉；继续已有全部能力 |

阶段按永久累计XP推导，不额外消费XP，达到阈值立即解锁。界面显示当前阶段、XP至下阶段的进度和下一解锁；最高阶段显示已全部开放。跨多个阈值一次处理，不漏中间解锁。未解锁条目可查看要求，但不能建造；被锁/费用不足提示在当前操作区出现，仍可查看世界或取消。

## 5. 自然生态

每累计50XP触发一次生态变化；事件跨越多个50XP边界时逐次处理。没有独立每日维护或离线衰退计时，不要求连续来访。

每次变化先尝试升级一个可成长自然对象（幼草/芽丛→灌木→成熟树，可复用已有素材；不拉伸已验收木屋或降低像素品质），无可升级对象时在合法空地增加一个植物。位置/选择确定性，存档记录对象阶段与坐标；空地不足时允许该次无新增并显示说明，不能挪走建筑硬凑变化。

保护：人工对象（包括人工树、花和装饰）的ID、类型、位置、收纳状态不变；不能占用人工对象占地、未解锁土地、门前预留道路。成熟树升级所需占地不够则选择其他合法对象/位置。自然可在新增土地延续生长；不会自动修改地形路径。

自然对象不收建造费；用户建造时可让占地内自然植被退让，但不自动破坏其他人工对象。退让只发生在用户确认合法建造后，预览/取消不删除植被。自然和人工对象数据分开，重渲不能重新随机布局。

## 6. 建造、收纳与土地

复用真实素材：陶土红木屋、阔冠树、青杉、草丛、野花、灌木、石头、横/纵栅栏、信箱。木屋approved；其他仍candidate，只由用户明确视觉确认才能升级状态。资产工程和来源保留。

| 对象 | 首次创建BP | 地面占地（格） |
| --- | ---: | --- |
| 木屋 | 24 | 3×2 |
| 草丛 | 1 | 1×1 |
| 野花 | 2 | 1×1 |
| 灌木 | 4 | 1×1 |
| 石头 | 3 | 1×1 |
| 阔冠树 | 10 | 2×2 |
| 青杉 | 10 | 1×1 |
| 横栅栏 | 3 | 2×1 |
| 纵栅栏 | 3 | 1×2 |
| 信箱 | 6 | 1×1 |

占地左上坐标为整数网格；完整占地必须在已解锁区块内，不能与未收纳人工对象占地重叠。视觉锚点从素材anchor与footprintOffset映射，不将画布/树冠当占地。按地面脚点排序；Alpha可见区域命中与地面占地命中区分，缩放平移后坐标一致，透明像素不抢点击，实际可见前景对象优先。

选择目录→预览→点地图定位→显示合法性和价格→确认创建并扣费。预览/取消不扣费、不改变世界。移动保留同ID；收纳后x/y为空且进入收纳列表；重新摆放沿用同ID，三项均0BP，不退款、不重复收首次费。不能利用收纳生成新对象或资源。初始赠送木屋也可免费移动/收纳/重摆。

初始区块8×8格。每次扩张一个8×8相邻区块，价格20BP，扎根阶段开放；允许四周和负区块坐标，不能跳过未连通土地、重复买同块或越界。确认前明确区域和20BP，成功后一次扣费、连续铺草地、可在新土地建造。同一对象可跨已开放区块边界，占地规则不变。原建筑与道路保持原坐标，不按扩张尺寸重新居中数据。

## 7. 新用户体验

初始XP0/BP30、8×8林缘草地；赠送一栋已验收木屋（逻辑左上2,2），有通门小路、有限自然树/花/草与足够空地。布局由配置确定，不将旧P2-B场景或用户P1存档作为新的已消费进度导入。

首屏看见自己的世界、XP/BP、阶段、“记录模拟努力”“建造”“扩张”“收纳”入口。简短提示先摆一簇花或记录一次努力；非强制教程，不阻挡建造。不要求姓名、目标创建、账号或权限开通。首次赠送只随创建新世界发生，不在每次刷新/恢复重复赠送。

## 8. 持久化与故障

独立localStorage键`mingrifu-growth-game-v1`，schemaVersion=1；保存世界区块、人工与自然对象、XP、BP、事件记录、revision、ID生成状态。不读写P1键`mingrifu-growth-world-p1-v1`、V3会话键或V4数据。用户/端口/域名数据不跨来源共享，当前没有云备份承诺。

先校验命令，再完成存储写入，再提交可见世界/资源/阶段。写失败时旧世界保持不变，显示明确的重试与取消；重试相同事件/建造不能再次扣/发资源。跨标签保存用同源Web Locks序列化读-校验token/revision-写，发现冲突暂停写入并要求重新读取，不能覆盖另一页的新状态；不能仅依赖非原子的localStorage先读后写。锁能力不可用时保持只读并明确提示，不能悄悄降级为不安全写入。独立服务通过localhost/安全上下文运行。

损坏、未知版本或禁止访问的存档保持原值，不自动清理或覆盖；显示只读预览与恢复说明，可重新读取/下载原始记录。新用户保存失败也明确提示，不装作已永久保存。第一版不做自动P1迁移，不增加任意JSON导入/旧档回滚流程。

## 9. 桌面与移动

桌面：Canvas世界可拖动/缩放；目录与确认操作容易访问；键盘方向键调整预览，Enter确认、Escape取消，已有对象操作显示选中状态。

手机320/390px宽度：地图保持可见；目录底部抽屉、选择后收起；建造/移动/扩张确认和取消固定同屏，错误提示与操作同区，兼容安全区与短屏。点击与拖动阈值区分，拖地图不建造；预览不能阻止相机操作。无需为了选对象和确认反复上下滚动。

相机保留软边界、“世界总览”、整数最近邻放大与足够缩小档位；总览计算已解锁土地和对象视觉范围，扩张后可完整适配。0.5以下总览允许细节减少，不能以模糊缩放掩盖素材质量。非必要的大动画/双指手势不作为MVP阻断项。
