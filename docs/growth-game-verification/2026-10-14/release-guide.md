# 独立成长游戏体验说明

本文件随最终实际版本更新；验收结论与当前状态以growth-game.md/最终release报告为准。木屋沿用用户已验收样板，植物、地形和新构图仍为candidate。第一版所有努力均模拟，不接明日复真实任务数据。

## 运行

在项目根目录执行`npm run dev:game`，浏览器打开`http://127.0.0.1:5189/`。独立构建：`npm run build:game`；构建后`npm run preview:game`，打开`http://127.0.0.1:5190/`。输出仅dist/game，原应用入口/构建保留。不要从文件管理器直接双击HTML；本地服务为存档锁提供安全上下文。

开发与构建预览端口是不同来源，存档各自独立，不自动跨端口同步。保存键为mingrifu-growth-game-v1/schema1；不读取或覆盖P1/V3存档。正常保存需要浏览器的localStorage、Web Locks、IndexedDB和安全摘要能力；不可用时只读，故障时可重新读取和下载原始记录，不自动重置/清理。IndexedDB仅用于原子版本校验，不是另一份世界存档。

## 推荐体验顺序

1. 首次看到8×8林缘世界、赠送木屋、小路、自然植物，0XP/30BP。
2. 建造目录选择野花，点空地预览、确认，BP减2。试点屋的占地或边界外，应明确拒绝；取消不收费。
3. 点木屋屋顶/墙面选中，移动、收纳、从收纳盒重摆，三步不收费且同一对象。
4. 记录50、50、25分钟模拟努力，累计125XP，获得25BP，达到扎根阶段；观察50XP边界的自然变化，人工布局不被移动。最高300XP开放青杉。
5. 已达到120XP且有20BP，选择相邻8×8区域扩张，在新地建造；原建筑位置不移。世界总览可完整适配新地，滚轮/按钮缩放、拖动查看。
6. 刷新和关闭页面后重新打开相同地址，检查世界、XP/BP和收纳正确恢复。不来访不扣资源或破坏布局。

鼠标拖动只移动相机，点按用于选对象/定位预览；方向键调预览、Enter确认、Escape取消。手机目录为底部抽屉，选择后收起，地图与确认/取消/错误保持同屏。最高阶段后仍可自由布置与扩张，不加入维护或签到压力。

## 已知边界

数据仅在当前浏览器本地，不提供账号/云同步/自动旧档迁移/导入。清理浏览器数据会影响本地记录，跨标签冲突应重新读取，不覆盖别页新状态。技术容量保护与平衡参数位于balance.js/persistence.js，可后续调整；不是无限土地或奖励承诺。

更新版本后，刷新已经打开的独立游戏标签页；同一世界不混用旧代码页面。原生并发保护适用于都采用本次保存协议的页面，不承诺保护开发者工具或旧代码直接改写记录。

通常保存失败可重试同一操作或取消，旧世界不变。若同时发生世界写入失败和安全校验回滚失败，当前页会保留原操作、只允许安全重试；此时取消/重读不能丢掉恢复凭据，界面应说明原因，也可下载原始记录。

若浏览器进程恰好在版本校验预提交后、世界原文写入前中断，原世界仍保留，但校验版本不一致会使游戏保守只读。可下载原始记录，不自动猜测修复或覆盖；第一版不提供手工重置校验工具。已验证正常关闭浏览器后恢复，不承诺崩溃或断电情况下最后一笔写入的持久化；这与游戏的奖惩机制无关。

实际桌面/手机模拟、故障注入、测试、QA与截图在本目录最终release报告中；真机/Safari范围须按实测记录，不能把自动测试当用户美术或阶段产品验收。
