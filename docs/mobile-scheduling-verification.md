# V3 移动端排程适配验收

验证日期：2026-10-09。修改仅针对手机端核心排程流程，未推送或部署。

## 实现与范围

- 沿用原有 600px 响应式断点。手机端任务卡显示「安排」，打开现有行动详情面板；显示任务名称、日期、预计时长，可设置开始时间和持续时间，点击「确认安排」后切换「时间流」查看。
- 「取消」和右上角关闭按钮均只关闭面板，不提交编辑。
- 复用 `schedule` → `scheduleTask`、原有任务状态、冲突检测与 `sessionStorage`。不新增排程状态管理或服务。
- 延续原有规则：同一天内排程、至少 15 分钟；表单开始时间步长 15 分钟，时长步长 5 分钟。时间重叠允许保存并在时间流提示，其他任务不会自动移动。
- 桌面保留原有拖拽、保存时间与时长调整逻辑。手机端空状态提示改为点击操作说明。
- 未修改目标拆解、部署脚本、构建配置或依赖。

## 复验方式

1. 安装项目依赖后，以 `npm run dev -- --host 127.0.0.1 --port 5183 --strictPort` 启动本地预览。
2. 打开 `http://127.0.0.1:5183/`，浏览器响应式预览设为 390px 或 320px，进入待安排，点击「安排」。
3. 环境已有 Playwright 和 Google Chrome 时，运行 `node scripts/verify-mobile-scheduling.mjs`。无需新增产品依赖。
4. 可选环境变量：`BASE_URL` 指定测试服务地址；`PLAYWRIGHT_MODULE` 指定外部安装的 Playwright 模块位置；`QA_OUTPUT` 指定截图输出目录。默认从项目环境解析 Playwright，不使用本机绝对路径作为默认值。
5. 脚本若有可用 WebKit 会额外执行同一套手机尺寸测试；缺失时会明确输出跳过原因。
