## 命中、遮挡与相机规则

1. 渲染器与命中共用同一对象列表和整数屏幕矩形。屋顶、墙面、可见基座参与像素命中；透明边缘忽略。低于 100% 时，命中 mask 从浏览器实际最近邻缩放结果取得，避免命中被采样丢弃的边缘。
2. 从绘制顺序的最后一项反向查找，优先选择实际可见的前景建筑。可见植物挡住建筑时不会穿透植物选中隐藏部分；空白地面仍可以按占地选择建筑。
3. 选中占地、合法/非法占地提示均在地面层。建筑视觉预览按深度进入对象层，不再固定盖在所有对象上。拖动超过 7 CSS 像素即作为平移，释放不选点、不放置；建造始终需要单独确认。
4. 相机边界考虑已开放区块的内部参考点，而非一个空洞大包围框。拖出边界时有有限阻力，松手后回到允许位置；放大后仍可以查看远端土地。“回到世界”自动纳入已开放地块与屋顶/树冠。
5. 扩张候选全部显示，列表编号与地图标记对应；选择后高亮，确认前不改变土地或存档。

深度仍是当前平地、固定朝向对象的画家排序，不是通用 3D 遮挡系统。复杂交错占地、很密集树冠与未来高大建筑仍应增加专项场景验证。

## 三项候选美术与规范

源文件：`src/growth/sample-art.js`。导出 PNG：

- 木屋：`sample-cabin.png`，80×80 透明画布，地面锚点 (40,40)。完整墙体、山墙、屋檐、门窗、木板和小烟囱。
- 树：`sample-tree.png`，64×64 透明画布，根部锚点 (32,52)。直立树干、体积树冠与同光向色阶。
- 草地组：`sample-grass.png`，145×78 透明画布，展示 6×6 相邻地块；单地块逻辑面为 24×12，纹理由全局格坐标确定，内部没有重复岸边或单独描边。

### 投影与像素尺度

地面坐标转换：`screenX = (gridX - gridY) × 12`，`screenY = (gridX + gridY) × 6 - heightPixels`。屏幕 Y 向下，构件高度向上；所有脚点、墙底、屋顶和地表使用这套 2:1 斜俯视规则。

一格地面菱形为 24×12 逻辑像素，基础笔触为 1 逻辑像素。木屋占地 2×2 格，对应 48×24 的地面投影；墙高 18px，屋脊高 30px。树占用一个根部格，冠幅约 34px，总可见高度约 48px，与木屋体量相近。图像外部留白不等于碰撞或命中范围。

### 轮廓、阴影与色彩

共用暖深色轮廓 `#514e3c`，主体约 1px 像素边缘；曲线用阶梯与块面，不平滑插值。左上受光，右侧/下侧用较深色阶；木屋使用暖木色、陶棕屋顶、暖窗，树冠与草地使用同一低饱和绿色家族。地面接地/投影阴影单独绘制，朝右下延伸；阴影不加入建筑命中 mask。

房屋先绘实体墙与两端山墙，再铺屋顶并留少量檐口。禁止屋顶和墙之间出现无意透明缝隙。草地底色连续，局部纹理少量变体，岸边只出现在开放土地的外侧。

### 后续新增建筑的条件

候选方向具备扩展所需的坐标、锚点、笔触、调色板、结构层和阴影约定，但须先经用户视觉确认。确认后，每个新类型需定义整数占地、按投影构建完整实体、保持像素尺度与光向，单独验证透明命中 mask、相邻遮挡、普通/近景和手机尺寸。不能通过扩大模糊贴图来补齐结构问题。树的成长阶段、更多建筑类别与额外装饰尚未按本样板制作。

来源和许可见 `public/assets/growth-p1/SOURCE.md`。候选样板是本轮原创程序像素绘制，供本项目使用，未声明单独公开素材许可；原 P1 对比植物保留其 CC0 来源。

## 当前限制

- 没有滚轮或双指缩放，仍使用已有按钮；单指拖动可用。
- 超低倍率用于总览，细节与点击区域会很小，建造入口自动提高工作倍率；非常大的世界尚未进行性能测量。
- 当前绘制深度适用于 P1 的平地/固定朝向场景；复杂交错、高建筑和密集树冠尚需扩展验证。
- 真实 iOS Safari、Android、微信、安全区域硬件、屏幕阅读器与横屏/平板流程尚未验证。环境 WebKit 可执行文件缺失，未安装依赖来补跑。
- 候选美术仅是一栋木屋、一棵树、一组草地；未推广到存档世界、其他建筑和完整植物成长阶段。当前 P1 世界继续使用临时素材。
