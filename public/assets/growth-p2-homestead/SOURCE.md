# 明日复 P2-B 素材来源

本目录素材由本项目的免费 Blender / Node 像素生产脚本原创制作。未使用 PixelLab、付费 API、购买素材、收费插件或《星露谷物语》游戏素材。

- `cabin-terracotta.png`：2026-10-13 木屋实验中用户已验收的原始 Sprite，按原字节复制。本轮用户 P2-B 请求明确确认其美术品质；原始工程和图片没有修改。标为 approved 的只有这项基准素材。
- 树木、草丛、野花、灌木、石头、栅栏、信箱：2026-10-14 原创语义 3D 模型，Blender 4.5.14 LTS / Cycles CPU / 南侧正交相机，原生尺寸渲染并作确定性色板、Alpha 和外轮廓处理。
- `terrain-atlas.png`：原创整数像素纹理簇与 47 状态地形连接规则，8 种草地、两种土地各47种连接图块，以及2种长直道路纹理变化。没有模糊过滤或烘焙整个家园。
- 所有新素材和整体家园标为 candidate，等待用户视觉验收。工具检查通过不代表最终美术验收。

逐项尺寸、锚点、占地、视觉边界、源工程、生产方式、排序、色板、版本与状态见 `manifest.json`。源代码、真实 `.blend`、原始渲染、逐块地形 PNG、失败记录与截图保存在 `docs/growth-p2-b/2026-10-14/`。

软件沿用项目中已经安装的免费工具；未为项目成果另行设定新的发布许可。
